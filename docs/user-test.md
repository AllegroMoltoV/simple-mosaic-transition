# ユーザーテストの依頼

## はじめに

シンプルモザイクトランジションの使い心地を、普段お使いの OBS Studio で確かめていただくための手順です。ポータブル版の OBS Studio での自動のシナリオテストは、すべて合格しています ([結果](reports/2026111502-obs-scenario-test.md))。自動では判定できない、見た目と使い心地と音を確かめていただきます。所要時間は 15 分ほどの見込みです。

最後に、配信プラグイン倉庫くんと README に載せる説明の GIF の収録もお願いします。

## 準備

プラグインは、`%PROGRAMDATA%\obs-studio\plugins\simple-mosaic-transition\` に導入済みです。

1. OBS Studio を起動してください。ほかのセッションが OBS Studio を使っていないことを先にお確かめください。
2. シーンを 2 つ以上用意してください。普段の配信のシーンをそのまま使ってかまいません。音声のあるシーンが 2 つあると、手順 5 で音のつながりを確かめられます。

## 手順

1. シーントランジションの **+** ボタンから **シンプルモザイクトランジション** を追加し、選んでください。
2. 歯車のボタンから **プロパティ** を開き、項目と既定値をご覧ください。暗転部分の長さ 50%、モザイクの最大の粗さ 64 px、切り替えの位置 50% のはずです。
3. 期間を 1,000 ms ほどにして、シーンを何度か切り替えてください。
4. 次の値を変えて、見え方を比べてください。
   - 暗転部分の長さ: 0%・50%・100%
   - モザイクの最大の粗さ: 8 px・64 px・256 px
   - 切り替えの位置: 30%・50%・70%
   - 期間: 300 ms・1,000 ms・2,000 ms
5. 音声のある 2 つのシーンを切り替えて、音のつながりをお聞きください。
6. あるシーンのソースを右クリックし、**非表示トランジション** にこのトランジションを選んでから、そのソースを非表示にしてください。OBS Studio が応答を続け、ソースが消えることをお確かめください。
7. スタジオモードで T バーをゆっくり動かし、途中で戻してみてください。

## 確かめていただきたいこと

- 気絶の演出らしく見えますか。
- 既定の粗さと期間は適切ですか。
- 暗転部分の長さを 0% にしたときの切り替わりは自然ですか。
- 暗転部分の長さ、モザイクの最大の粗さ、切り替えの位置という項目名は分かりやすかったですか。
- 音のつながりに違和感はありませんか。
- 非表示トランジションと T バーで、おかしな見え方はありませんでしたか。
- そのほか気になったことはありますか。

感想は箇条書きで送っていただければ、一覧に整理して対応案と一緒にお返しします。

## 説明の GIF の収録

使い心地の確認で直す点が無ければ、トランジションの様子を GIF に収録してください。直す点があれば、直したあとで収録をお願いします。

- 保存先: `.soko-kun/image.gif`
- 大きさ: 1.5 MB 以内
- 内容: シーンを切り替えて、モザイクが粗くなり、次のシーンで細かく戻る様子。特定のゲームの画面や音は映さないでください。
- 収録の方法: シンプルモザイクでは ScreenToGif で画面を収録しました。
